# OCR 场景使用指南

本指南汇总 Deep Core OCR 的五大典型使用场景。每个场景都会标注其任务类型：

- **纯 OCR**：主要目标是把图片中的文字“抠”出来，对物体、场景、语义理解要求不高。
- **视觉理解 + OCR**：需要先理解图片整体内容（物体、布局、场景关系），再提取或解释文字。

---

## 场景一：纸质文档数字化归档与智能整理（线下纸质场景）

### 一、任务类型

**纯 OCR**

### 二、OCR 核心用途

解决纸质合同、票据、报表、档案、手写单据无法电子化检索、编辑、归档的痛点。针对拍摄扫描的纸质文件影像，OCR 精准识别印刷体、规范手写体文字，还原文档原有段落、行列排版结构，将静态图像转化为可编辑、可检索、可整理的纯文本，是线下资料数字化的核心基础能力。

### 三、具体使用指南

1. **图像采集**：通过扫描仪、手机拍摄纸质文件，保证画面平整、光线均匀、无反光、无倾斜，完整覆盖文档内容区域。
2. **OCR 调用**：开启文档专项识别模式，支持版面分析、行列还原、标点精准识别，自动矫正倾斜图像、去除拍摄阴影、污渍噪点，保留文档原有排版结构。
3. **内容整理**：将 OCR 识别文本送入大模型，自动纠错、规整段落、拆分章节、剔除空白无效内容，整理为规范文档格式。
4. **落地输出**：生成 Word、Markdown、PDF 可编辑文档，用于企业档案归档、纸质资料电子化留存、办公资料标准化整理。

### 四、推荐模型

- **DeepSeek-OCR（纯 OCR）**：印刷体文档、规范排版，速度快、成本低
- **Qwen2.5-VL（视觉理解）**：中英文混合、复杂表格、手写批注

## 场景二：桌面业务截图信息提取与汇总（系统客户端场景）

### 一、任务类型

**OCR + 视觉理解**

### 二、OCR 核心用途

适配各类 PC 客户端、后台管理系统、软件控制台、弹窗报错、业务账单等无法爬虫抓取的桌面截图画面。OCR 精准识别软件界面内的业务数据、报错代码、订单信息、设备参数、日志文本，突破网页局限，覆盖全桌面端图像信息采集。

### 三、具体使用指南

1. **图像采集**：对电脑客户端、后台系统、软件弹窗、设备控制台界面进行全屏/局部截图，确保业务数据、报错信息、参数内容完整显示。
2. **OCR 调用**：开启界面细粒度识别模式，适配软件小字、灰度文字、代码字符、特殊符号，精准识别高密度排版的界面文本，保留信息对应关系。
3. **内容整理**：依托 OCR 识别结果，通过大模型分类梳理业务数据、解析报错原因、汇总设备参数、提炼日志核心信息。
4. **落地输出**：生成结构化数据、问题分析报告、业务汇总表格，用于运维排查、业务对账、系统日志整理、客户端数据统计。

### 四、推荐模型

- **Qwen2.5-VL（视觉理解）**：界面文字、代码、符号识别能力强，能理解界面布局
- **DeepSeek-OCR（纯 OCR）**：清晰界面、纯文本弹窗

## 场景三：实物影像信息识别与结构化录入（实景拍摄场景）

### 一、任务类型

**视觉理解 + OCR**

### 二、OCR 核心用途

针对手机实拍的实物影像，包括证件、铭牌、标签、票据、物料标牌、商品外包装等实景图片。OCR 可精准识别自然场景下的非标准排版文字，抗角度倾斜、光线偏差、背景杂乱，提取实物载体上的关键信息，实现线下实物信息自动化录入。

### 三、具体使用指南

1. **图像采集**：手机近距离拍摄实物载体，聚焦文字区域，尽量避开杂乱背景，保证关键文字清晰可辨。
2. **OCR 调用**：开启通用实景识别模式，自动适配倾斜文字、曲面文字、背景干扰画面，精准提取编号、日期、规格、证件信息、批次号等核心内容。
3. **内容整理**：大模型对 OCR 零散文本进行清洗归类，提取关键字段，剔除背景干扰文字、无效杂质信息，形成标准化信息条目。
4. **落地输出**：输出结构化字段信息、实物信息台账，用于物料入库登记、证件信息录入、设备台账更新、商品信息归档。

### 四、推荐模型

- **Qwen2.5-VL（视觉理解）**：通用实景、铭牌标签
- **MiniMax-M3（视觉理解）**：复杂背景、小字、多语言、兜底

## 场景四：网页 UI 文案与内容合规校验（线上网页场景）

### 一、任务类型

**纯 OCR**

### 二、OCR 核心用途

作为唯一保留的网页类场景，聚焦网页对外展示内容的合规与文案校验，区别于视觉差异比对。OCR 全量抓取网页所有可见文案、弹窗提示、营销话术、底部声明，解决网页动态渲染文字、悬浮文字、小字声明无法批量抓取的问题，为网页内容风控、文案标准化校验提供完整文本支撑。

### 三、具体使用指南

1. **图像采集**：完整截取网页落地页、活动页、功能页、弹窗、底部公示区域，全覆盖所有对外展示视觉内容。
2. **OCR 调用**：开启网页高清识别模式，精准识别浅色小字、遮罩文案、动态悬浮文本，无遗漏抓取页面全部公开文字内容。
3. **内容整理**：基于 OCR 全量文本，完成敏感词筛查、违规营销话术校验、文案统一性核对、合规声明完整性校验。
4. **落地输出**：生成网页内容合规报告、文案校对清单，用于网站上线质检、日常风控巡检、品牌文案标准化管控。

### 四、推荐模型

- **DeepSeek-OCR（纯 OCR）**：网页印刷体、清晰文案
- **Qwen2.5-VL（视觉理解）**：复杂页面、中英文混合、小字

## 场景五：证件 / 发票 / 票据信息自动录入（业务凭证场景）

### 一、任务类型

**OCR + 版式理解（视觉理解的子能力）**

### 二、OCR 核心用途

针对身份证、驾驶证、营业执照、增值税发票、普通发票、收据、机票行程单、银行回单等具有固定版式的业务凭证。OCR 精准定位凭证中的关键字段区域，识别字段名称与对应值，解决人工录入效率低、易出错的问题，实现财务、人事、行政、供应链等业务凭证的自动化录入与核验。

### 三、具体使用指南

1. **图像采集**：将凭证平铺拍摄或扫描，确保四角完整、文字清晰、无反光遮挡；证件类建议拍摄正反面并保留边框。
2. **OCR 调用**：开启结构化识别模式，结合版式分析定位发票代码、发票号码、金额、日期、购方/销方名称、证件姓名、身份证号、有效期等关键字段。
3. **内容整理**：大模型根据凭证类型自动匹配字段模板，校对数值格式（如金额大写小写一致性、日期合法性），剔除印章干扰文字。
4. **落地输出**：输出 JSON / Excel / 数据库记录，用于报销系统对接、财务自动记账、身份核验、供应链单据归档。

### 四、推荐模型

- **Qwen2.5-VL（视觉理解）**：版式理解、字段提取
- **MiniMax-M3（视觉理解）**：复杂版式、低质量图片、兜底

### 五、常用字段模板示例

**增值税发票**：

```json
  "发票代码": "",

  "购买方名称": "",
  "销售方名称": ""
}
```

**身份证**：
```json

  "出生日期": "",
```

## 通用调用示例

```bash
# 场景一/四：纯 OCR 任务，优先 DeepSeek-OCR
python scripts/ocr.py \
  --image input/document.png \
  --provider deepseek-ocr \
  --output output/document.txt

# 场景二/三/五：需要视觉理解 + 结构化
python scripts/ocr.py \
  --image input/invoice.png \
  --provider qwen-vl \
  --mode structured \
  --prompt "提取发票编号、金额、日期、供应商，输出 JSON" \
  --output output/invoice.json

# 复杂实景兜底，需要强视觉理解能力
python scripts/ocr.py \
  --image input/scene.jpg \
  --provider minimax-m3 \
  --mode structured \
  --prompt "提取图片中所有可见文字和关键信息" \
  --output output/scene.json
```

## 任务类型判定口诀

```
画面干净、只有字 → 纯 OCR → DeepSeek-OCR
需要看布局、看物体、看场景 → 视觉理解 → Qwen2.5-VL / MiniMax-M3
复杂、模糊、多语言、没把握 → MiniMax-M3 兜底
```
