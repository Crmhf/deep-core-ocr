# OCR Prompt 编写指南

好的 Prompt 能显著提升 OCR 识别准确率与输出可用性。本指南提供 Deep Core OCR 常用 Prompt 模板与编写原则。

## 一、先区分任务类型

本技能调用的模型分为两类，Prompt 写法应有所区别：

### 纯 OCR 任务

- **目标**：把图片中的文字原样“抠”出来
- **适用模型**：DeepSeek-OCR
- **Prompt 特点**：简短、直接、明确“只输出文字”
- **示例**：
  ```
  请输出图片中的全部文字内容。
  ```

### 视觉理解 + OCR 任务

- **目标**：先理解图片（物体、布局、场景），再提取或解释文字
- **适用模型**：Qwen2.5-VL、MiniMax-M3
- **Prompt 特点**：可以要求分析、归类、结构化；允许模型理解上下文
- **示例**：
  ```
  图片是一张发票，请提取发票编号、金额、日期、供应商，输出 JSON。
  ```

## 二、Prompt 编写原则

### 1. 任务明确

直接说明要做什么，避免模糊表达。

- ❌ "看看这张图"
- ✅ "请识别图片中的所有文字，并原样输出。"

### 2. 输出格式清晰

需要结构化输出时，明确指定格式（JSON、列表、表格）。

- ❌ "提取信息"
- ✅ "提取发票编号、金额、日期，输出 JSON 格式：{\"发票编号\": \"...\", \"金额\": \"...\", \"日期\": \"...\"}"

### 3. 约束边界

说明不需要的内容，减少模型发挥。

- ❌ "识别文字"
- ✅ "只输出图片中的文字内容，不要解释，不要总结。"

### 4. 场景化用词

不同场景使用模型更易理解的表达：

| 场景 | 推荐表达 |
|------|---------|
| 纯 OCR | "识别图片中的所有文字" / "请输出图片中的全部文字内容" |
| 发票 | "提取发票编号、金额、日期、购买方、销售方" |
| 证件 | "提取姓名、性别、民族、出生日期、身份证号、住址" |
| 网页 | "提取网页截图中所有可见文案，包括按钮、弹窗、底部声明" |
| 报错 | "提取错误代码、错误信息、按钮文字" |
| 实物 | "提取铭牌/标签上的型号、规格、生产日期、批次号" |

## 三、按模型推荐 Prompt

### DeepSeek-OCR（纯 OCR）

该模型对简短直接的 Prompt 响应较好：

```
请输出图片中的全部文字内容。
```

```
识别图片中的文字，保持原有排版。
```

### Qwen2.5-VL（视觉理解）

通用能力强，适合复杂指令：

```
请识别图片中的所有文字，并原样输出，不要添加解释。
```

```
请提取图片中的关键信息，并以 JSON 格式输出：
- 字段1：...
- 字段2：...
```

### MiniMax-M3（视觉理解）

复杂场景、多语言、兜底：

```
请仔细识别图片中的所有可见文字和关键信息，输出完整内容。
```

```
图片是一张 [发票/身份证/标签/网页截图]，请提取其中的关键字段并结构化输出。
```

## 四、常见场景 Prompt 模板

### 模板 1：纯文字提取（适合 DeepSeek-OCR）

```
请识别图片中的所有文字，保持原有段落和换行，不要添加任何解释。
```

### 模板 2：发票结构化（适合 Qwen2.5-VL / MiniMax-M3）

```
请识别这张发票图片，提取以下字段并以 JSON 输出：
{
  "发票代码": "",
  "发票号码": "",
  "开票日期": "",
  "购买方名称": "",
  "销售方名称": "",
  "金额（不含税）": "",
  "税额": "",
  "价税合计": ""
}
```

### 模板 3：证件识别（适合 Qwen2.5-VL / MiniMax-M3）

```
请识别这张身份证图片，提取以下字段并以 JSON 输出：
{
  "姓名": "",
  "性别": "",
  "民族": "",
  "出生日期": "",
  "住址": "",
  "公民身份号码": "",
  "签发机关": "",
  "有效期限": ""
}
```

### 模板 4：软件截图信息提取（适合 Qwen2.5-VL）

```
请识别这张软件截图，提取所有可见文字，包括：
- 标题栏文字
- 菜单和按钮文字
- 错误代码和提示信息
- 表格数据
以列表形式输出，保持层级关系。
```

### 模板 5：网页文案抓取（适合 DeepSeek-OCR / Qwen2.5-VL）

```
请提取网页截图中的所有可见文案，包括：
- 导航栏和标题
- 正文内容
- 按钮和链接文字
- 弹窗提示
- 底部声明和小字
不要遗漏任何文字。
```

### 模板 6：实物标签识别（适合 Qwen2.5-VL / MiniMax-M3）

```
请识别这张实物标签图片，提取以下信息：
- 产品名称
- 型号规格
- 生产日期
- 批次号
- 制造商
- 条形码/二维码内容（如有）
输出为 JSON 格式。
```

## 五、Prompt 优化技巧

### 1. 分步骤指令

对于复杂图片，可以分步骤：

```
第一步：识别图片中的所有文字。
第二步：根据文字内容判断图片类型（发票/身份证/标签/网页等）。
第三步：提取该类型图片的关键字段并以 JSON 输出。
```

### 2. 提供字段示例

当需要结构化输出时，给出具体字段名和格式：

```
请输出以下字段：
- 发票编号：字符串
- 开票日期：YYYY-MM-DD
- 金额（元）：数字
```

### 3. 处理识别错误

如果识别结果有偏差，可以要求模型校验：

```
请识别图片中的文字，并对可能的识别错误进行合理修正。
```

## 六、避免的 Prompt

- ❌ 过于开放："描述这张图片"（除非你需要视觉描述而非 OCR）
- ❌ 歧义表达："把字拿出来"
- ❌ 缺少格式要求："提取信息"
- ❌ 过度复杂：一次性要求太多不相关任务

## 七、实战示例

### 示例 1：纸质合同 OCR（纯 OCR）

```bash
python scripts/ocr.py \
  --image input/contract.png \
  --provider deepseek-ocr \
  --prompt "请输出图片中的全部文字内容，保持段落格式。" \
  --output output/contract.txt
```

### 示例 2：发票结构化（视觉理解 + OCR）

```bash
python scripts/ocr.py \
  --image input/invoice.png \
  --provider qwen-vl \
  --mode structured \
  --prompt "提取发票代码、发票号码、开票日期、金额、购买方名称、销售方名称，输出 JSON。" \
  --output output/invoice.json
```

### 示例 3：网页合规（纯 OCR）

```bash
python scripts/ocr.py \
  --image input/webpage.png \
  --provider qwen-vl \
  --prompt "提取网页截图中的所有可见文案，包括按钮、弹窗、底部声明，不要遗漏。" \
  --output output/webpage-copy.txt
```

### 示例 4：复杂实景兜底（强视觉理解）

```bash
python scripts/ocr.py \
  --image input/scene.jpg \
  --provider minimax-m3 \
  --mode structured \
  --prompt "这张图片拍摄的是什么场景？请提取图中所有可见文字和关键信息，输出 JSON。" \
  --output output/scene.json
```
